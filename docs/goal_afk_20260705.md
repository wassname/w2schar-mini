## Operating rules (the 4-hourly loop)

- `pueue status --json | jq` first. Live run → checkpoint audit (patient mode): read
  latest round artifacts + log tail; KILL+FIX only with a root-caused quote (never on
  a guess); requeue with `-l "why: ...; resolve: ..."`.
- GPU idle → (a) archive+push the finished run's artifacts per UAT-4, (b) full
  `/audit-run` via a context-free subagent, (c) journal, (d) apply ONE queued harness
  task (#4 then #5), `just smoke`, commit, (e) queue the next run
  (`just run qwen36-27b-3keep 12`-class profile) and note which single change it tests.
- Keep the GPU busy: there should always be a run Running or Queued after each firing.
- Discipline: fail fast, no defensive programming; one logical change per commit;
  smoke after any code edit; `/audit-run` command (not freehand) on completed runs;
  never `pueue reset`; leave other agents' tasks alone; MAX_DROPS/max_rounds are the
  only sanctioned halts.
- Teacher-facing text changes (prompts.py/gates) need `just smoke-prompts 1` (~$1) —
  batch them; read the artifacts, don't just check exit 0.
